# Glossary

**Answers:** What does an IDMC term, acronym, object type, header or id shape mean, or one of this KB's own words, and
which doc explains it?

**Read when:** a term in a doc, an error or an API answer is unfamiliar, or two docs seem to use one word differently.

**Key rules:**
- Ids have two shapes: the 6-character v2 org id prefixes every v2 object id; the 22-character v3 id is the one the
  identity APIs want (L-AUTH-048).
- A header belongs to a plane, not to a session (L-AUTH-001).
- A job is one task run or one taskflow run; CAI invocations are not jobs (L-IPU-041, L-CAI-038).
- `downloads/` on an agent is a live package store, not a cache (L-AGENT-094).
