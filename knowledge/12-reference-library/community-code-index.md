# Community code index: where other people's IDMC code does each thing

**Answers:** For a lesson that came from public code, where is the original implementation? Which public repository
already does the thing I am about to build?

**Read when:** you want a working example of a route or pattern before writing your own; you are checking a
**Reported** lesson against the code it came from.

**Key rules:**
- Every lesson listed here is **Reported** (third-party code, not probed here) or **Documented** (the vendor's own
  Claude skill). Probe a route on your org before relying on it, then record the result as a lesson (L-MCP-137).
- Read, do not copy: most of these repositories carry no license, and one is GPL. Check the verdicts in
  [Ecosystem](../09-claire-mcp/07-ecosystem-plugins-registries-community-tools.md) §4 before using any code.
- Never run community code against a production org first (L-MCP-124, L-MCP-137).
